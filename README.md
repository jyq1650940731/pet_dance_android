# pet_dance 安卓客户端

面向中国大陆安卓用户的宠物短视频客户端，对应 `docs/PRD.md` 的用户端和 `docs/prototype.html` 的信息架构。界面是深暖色，封面撑满卡片，主按钮用浅色。

这一版对接已经上线的 App 接口：

- 价值页同意协议后再出现手机号
- 可跳过的宠物类型和兴趣引导
- 未登录浏览模板、主推、分类，按宠物类型把匹配模板排到前面
- 模板详情循环播放预览，默认静音
- 相册或系统相机选图，裁成 9:16，长边 1280 的 JPEG 后上传
- 登录、验证码、点数不足、维护中，再创建任务
- 每 3 秒查询生成状态，可以离开页面
- 播放、保存到相册、系统分享、同一模板再做一条
- 第一次成功出片后询问应用商店评分
- 作品列表和删除、退出登录、注销账号、修改宠物类型

支付、订单和举报的服务端接口还没有。购买页按原型列出三个加油包，但不会假装支付成功。举报通过系统分享发出。

## 环境

- Android 8.0 及以上（minSdk 26）
- JDK 17
- Android SDK 35

在 `local.properties` 写上本机 SDK：

```
sdk.dir=C:\\Users\\you\\AppData\\Local\\Android\\Sdk
```

调试包默认请求 `http://10.0.2.2:8080/`，这是模拟器访问电脑的地址。先在 `server` 目录把接口跑在 8080。真机可以执行 `adb reverse tcp:8080 tcp:8080`，再在设置里把接口改成 `http://127.0.0.1:8080/`。设置里的地址重新打开应用后生效。接口返回的 `127.0.0.1` 媒体地址会自动改写成当前接口主机。

开发环境验证码是 `246810`。登录页在调试包里会提示。

## 运行

```powershell
.\gradlew.bat :app:assembleDebug
```

安装调试包后，从价值页走到制作页即可提交一条任务。当前服务端把模板预览片复制为成片。
